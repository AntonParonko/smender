# Smender

Smender — Android-приложение для пересылки входящих **SMS** и событий **входящих/пропущенных звонков** в Telegram.

## Что умеет приложение

- Отслеживает входящие SMS.
- Отслеживает входящие и пропущенные звонки.
- Складывает события в очередь доставки (outbox), если отправка временно недоступна.
- Автоматически отправляет сообщения в Telegram с:
  - номером отправителя/звонящего,
  - текстом SMS или фактом звонка,
  - именем устройства,
  - уровнем и статусом батареи.
- Показывает статистику и состояние очереди: отправлено / в очереди / ошибки.

## Короткая инструкция по использованию

1. Установите и откройте приложение.
2. Выдайте запрошенные разрешения (SMS, звонки и т.д.).
3. Откройте **Telegram settings**.
4. Введите **Bot Token** и **Chat ID**.
5. Сохраните настройки и отправьте тестовое сообщение.
6. После успешного теста приложение начнет пересылать новые SMS и звонки в ваш Telegram-чат.

## Подключение Telegram

1. В Telegram откройте `@BotFather`.
2. Создайте бота командой `/newbot` и получите **Bot Token**.
3. Откройте `@userinfobot` (или аналог) и получите свой **Chat ID**.
4. Вставьте Token и Chat ID в настройки Smender.
5. Нажмите «Отправить тестовое сообщение» и убедитесь, что сообщение пришло.

## Разрешения и зачем они нужны

- `READ_SMS` / `RECEIVE_SMS` — чтение и обработка входящих SMS.
- `READ_CALL_LOG` / `READ_PHONE_STATE` — определение входящих/пропущенных звонков.
- `INTERNET` / `ACCESS_NETWORK_STATE` — отправка сообщений в Telegram и проверка сети.
- `RECEIVE_BOOT_COMPLETED` — восстановление фоновой работы после перезагрузки.
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` — стабильная работа в фоне на устройствах с агрессивной экономией энергии.

Также в интерфейсе есть подсказки по:
- отключению ограничений батареи,
- фоновому режиму,
- автозапуску (для оболочек, где это требуется).

## Важно

- Приложение работает только при корректно настроенном Telegram-боте и выданных разрешениях.
- Если сети нет, события остаются в очереди и отправляются позже.
